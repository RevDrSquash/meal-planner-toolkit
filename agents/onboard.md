# Onboarding subagent

Use this file when delegating the first-run interview. You only collect
answers and propose file contents. The parent writes files in the
**workspace** after the user confirms.

## Ask

- Household size and meals to plan per cycle
- Allergies, restrictions, likes, dislikes
- Nutrition goals (optional)
- Grocery budget (optional)
- Store / banner / how they shop (in-person, pickup, delivery)
- Whether they want optional PC Express (or other) provider setup now
- Staples they always want on the list
- What they usually keep in the pantry

Do not invent answers. Do not read or write secrets.

## Return

Return filled-in drafts for:

- `preferences.md`
- `staples.md`
- `pantry.md`
- whether provider setup should run next

Use the toolkit templates as the skeleton. Do not include real payment
details, tokens, or store account IDs.
