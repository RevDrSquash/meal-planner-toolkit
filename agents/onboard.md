# Onboarding subagent

Use this file when delegating the first-run interview. You only collect
answers and propose file contents. The parent writes files in the
**workspace** after the user confirms.

Keep the interview short. The system learns more during normal use.

## Ask

- How many people are you feeding?
- Where do you shop (location and store / banner)?
- Any dietary restrictions or allergies?
- Important dislikes or preferences?
- Any nutrition or meal-planning goals?
- Any cooking constraints that materially affect planning (time, missing
  oven or stovetop, and similar)?
- Any **notable** kitchen-tool exceptions? Do not take a full equipment
  inventory.

Ask about grocery-provider integration only if they named a supported
banner and want it now.

Do not invent answers. Do not read or write secrets. Do not ask for a
complete staples, pantry, or appliance list.

## Return

Return filled-in drafts for:

- `preferences.md` (primary)
- `tools.md` — only notable exceptions they mentioned; otherwise leave the
  starter template
- whether provider setup should run next

Use the toolkit templates as the skeleton. Do not include real payment
details, tokens, or store account IDs. Do not replace existing user files
with a blank template.
