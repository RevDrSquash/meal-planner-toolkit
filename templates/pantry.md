# Pantry

Items listed here are assumed to be on hand. The agent excludes them from
the shopping list and instead lists them in a **Pantry check** section on
each meal plan so you can confirm before ordering.

## How to use

- Edit this file when usual stock changes (add, remove, or rename).
- Tell the agent when you are temporarily out of something — it will add
  that item for this order without changing this file.
- Preferred store products belong in `shopping/product-mappings.md`.
