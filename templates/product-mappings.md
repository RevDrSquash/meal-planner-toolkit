# Product mappings

Learned ingredient → preferred product. Fill this in as you shop. Do not
put tokens, account IDs, passwords, or raw search results here.

Format (provider-specific IDs are optional; never invent one):

```
ingredient — Brand name, size (`optional-product-id`)
```

This file is the only durable shopping knowledge V2 needs. Shopping
lists stay with the meal plan.
